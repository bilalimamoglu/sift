## 0.5.0

### Added
- Added a conservative hook beta with explicit `sift hook match` and `sift hook run` entry points for a tiny known-preset command set.
- Added a shared adoption contract layer so `doctor`, install, agent previews, help, and docs all agree that `sift exec` is the default path and hook mode is only an optional shortcut.
- Added a tiny Codex-native `sift` skill and a tiny Claude-native `.claude/commands/sift/` command pack.
- Added a shared runtime-payload rendering layer so managed blocks and native payloads reuse the same product truth instead of drifting by copy-paste.
- Added lifecycle ownership checks for native payloads so generated Codex and Claude files are only updated or removed when `sift` can clearly prove ownership.
- Added contract, smoke, dist, and packaging coverage for the adoption path and runtime-native packaging path.

### Improved
- Improved install honesty: runtime installs now explain the difference between the CLI as the real runtime and the generated native guidance files as small helper surfaces.
- Improved runtime parity: Codex installs now produce both managed instructions and the generated skill; Claude installs now produce both managed instructions and the generated command pack.
- Improved safety for low-level lifecycle commands by refusing to overwrite or delete custom `SKILL.md` files or custom Claude command files.
- Improved first-contact docs and CLI help so users can understand what gets installed for Codex versus Claude without overestimating runtime parity or mistaking the native surfaces for a second execution system.

### Changed
- Completed Phase 2 adoption-friction work and Phase 3 runtime-native packaging work.
- Updated package version to `0.5.0`.
