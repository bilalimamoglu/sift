## 0.5.1

### Added
- Added a repo-local GitHub Copilot install target so `sift install copilot` can write `.github/copilot-instructions.md` without inventing a new global surface.
- Added coverage for Copilot installation in the CLI, unit, dist, and packaging paths.

### Improved
- Improved terminal prompt redraw so wrapped selection blocks are cleared by visual height instead of logical line count, which stops the install menu from scrolling when option text wraps.
- Improved install help and CLI routing so Copilot appears as an explicit install option alongside Codex, Claude, and Cursor.

### Changed
- Bumped package version to `0.5.1`.
