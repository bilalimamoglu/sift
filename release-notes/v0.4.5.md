## 0.4.5

### Added
- Added explicit `runtime.operationMode` support so `sift` can model `agent-escalation`, `provider-assisted`, and `local-only` as a real public contract instead of an implied behavior.
- Added a dedicated operation-mode helper and provider-model catalog so guided setup and install can explain fallback choices more clearly.
- Added broader test coverage for operation-mode config resolution, guided setup UX, install flow UX, and terminal prompt rendering.

### Improved
- Reworked install and guided setup into a mode-first flow with clearer plain-language explanations of when to use an agent, when to use provider fallback, and when to stay local-only.
- Improved installer and setup prompt polish with better banner treatment, stronger copy, color hierarchy, and visible back navigation support across the main decision surfaces.
- Made `provider-assisted` install continue directly into provider, model, and API-key setup instead of deferring that work to a second command.
- Improved `doctor`, runtime guidance, and managed agent instructions so they reflect the configured or effective operation mode more directly.
- Hardened wrapper-aware `exec` behavior so package-manager preambles no longer cause false insufficient results on silent-success `typecheck-summary` and `lint-failures` runs.

### Changed
- Updated docs and CLI help to align with the local-first, heuristics-first product story and the new operation-mode setup flow.
- Bumped package version to `0.4.5`.
